# Manim Projects

A collection of mathematical and computer-science visualizations created with [Manim](https://www.manim.community/).

## Projects

- [Consistent Hashing](Consistent%20Hashing/README.md): an animated lesson on hash rings, server membership changes, virtual nodes, and replication.
- [Spectral Clustering](Spectral%20Cluestering/README.md): a Manim-only lesson on similarity graphs, Laplacians, eigenvectors, and clustering.
